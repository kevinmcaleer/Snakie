# The same program, in Python

Look at this screen. The Python is the big pane now, and the blocks are a sliver
at the edge.

It is the *same file*. It always was.

## What you already know

Every one of these you have used:

| The block | The Python |
| --- | --- |
| forever | `while True:` |
| repeat 4 times | `for _ in range(4):` |
| wait 400 milliseconds | `time.sleep_ms(400)` |
| if … then | `if …:` |
| toggle LED on GP15 | `pin_15.toggle()` |
| move forward 100 | `turtle.forward(100)` |

The indented lines are the ones *inside* a block. That is all indentation means
in Python: the shape of the blocks, drawn with spaces.

## Now type in it

Click into the Python and change a number. Then watch the blocks.

They change too — because there is nothing to convert and nothing to press.
Blocks and text are two ways of looking at one program, and you can work in
either, or both.

## The divider is the control

Drag the line between the two panes. All the way one way and you have only
blocks; all the way the other and you have only code. There is a **white dot**
underneath, halfway along: that is the stop where you get both.

Most people end up leaving it near the middle for a long time, and then one day
notice they have not looked at the left-hand side in a week.

There is no moment where you stop being a blocks person and start being a Python
person. You have been writing Python since lesson one. This is the part where
you notice.
