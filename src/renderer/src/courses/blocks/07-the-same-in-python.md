# The same program, in Python

Look at this screen. The Python is the big pane now, and the blocks are peeking
beside it.

It is the *same file*. It always was.

## What you already know

Every one of these you have used:

| The block | The Python |
| --- | --- |
| forever | `while True:` |
| repeat 4 times | `for _ in range(4):` |
| wait 400 milliseconds | `time.sleep_ms(400)` |
| if … then | `if …:` |
| toggle LED on GP15 | `pin_15.toggle()` |
| move forward 100 | `turtle.forward(100)` |

The indented lines are the ones *inside* a block. That is all indentation means
in Python: the shape of the blocks, drawn with spaces.

## Graduate this file

Press **Graduate to Python** on the canvas — or just start typing in the Python
pane, which asks the same question.

Your blocks are saved beside it as a `.blocks.py` file, so nothing is lost. The
file becomes ordinary Python, and from here you type it yourself.

You have been writing Python since lesson one. This is the part where you notice.
