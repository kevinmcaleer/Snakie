# Arduino UNO R3

The classic Arduino board: an **ATmega328P** at 16 MHz with **5 V** I/O, 14 digital
pins (6 with PWM), 6 analog inputs, a USB-B socket and a 2.1 mm barrel jack.  It
runs Arduino sketches (C++).

## Pins

Pin names follow the board's silk. The GPIO number is the Arduino pin number, so
`D7` is 7 and `A0` is 14 (A0–A5 are D14–D19).

| Pins | What they do |
|------|--------------|
| **D0 / D1** | Serial RX / TX, shared with the USB serial — leave them free while uploading |
| **D3, D5, D6, D9, D10, D11** | PWM (`~` on the silk) |
| **D10–D13** | SPI: SS, COPI (MOSI), CIPO (MISO), SCK. The 6-pin ICSP header carries the same SPI signals |
| **A0–A5** | 10-bit analog inputs, also usable as digital pins |
| **SDA / SCL** | I²C, the same pins as **A4 / A5** (only one use at a time) |
| **D13** | the onboard **L** LED |
| **VIN** | 7–12 V in (the barrel jack feeds it too) |
| **5V / 3V3** | regulated outputs; 3V3 gives at most 50 mA |
| **IOREF** | tells shields the I/O voltage (5 V) |

⚠️ Each I/O pin can source or sink about **20 mA** (40 mA absolute maximum).

## 3D model

Arduino publishes no 3D model for the UNO R3 (its CAD download holds only the
Eagle board), so this one is generated by `scripts/arduino-uno-meshes.mjs` from
that board file (`UNO-TH_Rev3e.brd`, CC BY-SA 4.0): the real outline and
mounting holes, the headers, USB-B, barrel jack, the socketed ATmega328P and the
larger components as simple blocks.
