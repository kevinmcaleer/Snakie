- **The code and the board light up together.** Put the editor's cursor on a
  Pin variable (`motor_a_speed`) and its pin and label on the mini board are
  spotlighted: a pulsing ring on the pad, the label in bold, and the other
  used pins dimmed. The board scrolls the pin into view. The other way round,
  clicking a used pin on the mini board moves the editor's cursor to the line
  that defines its variable.
